# tagger

Apk for organize mangas.
  + Contains a ~custom database using msgpack and hashmap~ sqlite database with indices. [See Database](lib/db/database.dart)
  + Tag autocompletion. [See Add](lib/pages/add.dart)
  + Autodeletion for tags.
  + URL extractor from supported galleries :). [See Image Extractor](lib/extractor/image.dart)
  + Artist extractor from supported galleries :D. [See Artist Extractor](lib/extractor/artist.dart)
  + Filter for searching. [See Filter](lib/filter.dart)
  + A simple bar graph for view how many artist have each tag [See Statistic page](lib/pages/statistic.dart).
  + Check if an artist uploaded a new manga. [See check_update](lib/pages/home.dart)
  + Memoization check_update
  + Toast on success, error and warning
  + Prioritized accessibility for better experience (Focus image, Paste button, Search on press enter).
